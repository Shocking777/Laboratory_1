## Использование

### Калькулятор

Калькулятор запускается командой:

```bash
python -m toolkit calc "EXPRESSION"
```

Поддерживаются:

* сложение `+`;
* вычитание `-`;
* умножение `*`;
* деление `/`;
* целочисленное деление `//`;
* остаток от деления `%`;
* унарные `+` и `-`;
* целые и дробные числа.

Пример:

```bash
python -m toolkit calc "10 + 5 * 2"
```

Результат:

```text
20
```



Получить справку:

```bash
python -m toolkit calc --help
```

#### Решения, принятые во время разработки калькулятора
- Унарные `+` и `-` определяются в зависимости от предыдущего токена:если перед ним другой оператор или начало строки.Если знак унарный,то он прикрепляется к числу, если нет - наоборот, отделяется.
- Все пробелы между токенами сначала убираются, а затем проставляются заново в зависимости от исходного выражения.
- Разделил `tokenization`, `validation`, `calculation` на три разные файла, а затем объединил их отдельной функцией.
- Использовал вычисление через Decimal с описанной политикой округления, однако в случаях нахождения остатка у отрицательного числа (Например:`-121%3`) Используется тип `float()`.
- Сделал историю успешных вычислений через **JSON**.
- Выполнил преобразования выражения в **RPN** и вычисление стеком.

### Конвертер

Конвертер позволяет переводить единицы измерения.

Конвертер запускается командой:

```bash
python -m toolkit convert VALUE --from UNIT --to UNIT
```


Поддерживаемые единицы:

**Длина:**

* `mm`
* `cm`
* `m`
* `km`

**Масса:**

* `g`
* `kg`

**Температура:**

* `c`
* `f`
* `k`


Пример:

```bash
python -m toolkit convert 100 --from cm --to m
```

Результат:

```text
1.0
```

Получить справку:

```bash
python -m toolkit convert --help
```
#### Решения, принятые во время разработки конвертора
- Таблица конвертаций загружается из конфигурационного файла. Файл `configuration.json`
- Конвертация между разными группами единиц не допускается.
- Для температуры выполняется проверка значения на то, что оно больше абсолютного нуля.
- Единицы измерения не зависят от регистра.
- Для длины и веса выполняется проверка значения на то, что оно больше нуля.
